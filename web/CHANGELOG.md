# Parole UI change log

- Added Previous and Next, left/right swipe and arrow-key navigation. The deck wraps and opens each new card on its French side.

- Refreshed surfaces, progress, controls and heading hierarchy with lavender, pink and dark plum. Uses the Apple system font where available with system fallbacks.
- Established front-end as the UI branch. Pages publishes it with course data built from main.
